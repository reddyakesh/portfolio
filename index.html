Projects

Task Fusion

An AI-powered asynchronous task processing platform that efficiently manages background jobs using distributed workers and message queues.

Workflow

  • User submits a task.
  • Node.js server receives the request.
  • Task is pushed to RabbitMQ.
  • Celery workers process the task asynchronously.
  • Results are stored in MongoDB.
  • User receives real-time status updates.

Technology Stack

HTML • CSS • JavaScript • Node.js • Express.js • MongoDB • RabbitMQ • Celery • Redis • JWT

Deep Learning Web Platform for Sonogram-Based Lactation Stage Classification in Dairy Cows

A deep learning web platform that classifies the lactation stage of dairy cows from sonogram images to support veterinary analysis and dairy farm management.

Workflow

  • User uploads a sonogram image.
  • Image is preprocessed.
  • CNN model extracts image features.
  • Model predicts the lactation stage.
  • Prediction is displayed through the web interface.

Technology Stack

Python • TensorFlow/Keras • CNN • HTML • CSS • JavaScript • Flask • OpenCV
